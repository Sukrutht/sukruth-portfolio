# Sukruth T — Developer Portfolio

A responsive, single-page portfolio website for Sukruth T, Python Backend & Full Stack Developer.

## Run locally
Open `index.html` in any modern browser. No build step or dependencies are required.

## Publish
This site is designed for GitHub Pages. In the repository, open **Settings → Pages**, choose **Deploy from a branch** and select **main** / **(root)**, then save. The public site will be available at:
https://sukrutht.github.io/sukruth-portfolio/
